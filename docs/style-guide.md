# “被删改的圣典”视觉规范

## 核心概念

界面像一册曾被天堂批准、被地狱涂改、最后由人类重新装订的实体档案。主要冲突是完美排版与手工批注、权威正文与页边真实，而不是传统蓝红阵营对战。

禁止默认使用玻璃拟态、紫色渐变、厚重金边、漂浮贴纸或统一羊皮纸滤镜。

## 色彩

| 用途 | 色值 |
|---|---|
| 深墨背景 | `#101316` |
| 档案纸 | `#E8E0CD` |
| 高亮纸 | `#F4EDDC` |
| 正文墨 | `#211D19` |
| 天堂批注蓝 | `#6F899B` |
| 地狱批注朱红 | `#A34F3E` |
| 人间苔绿 | `#6D7862` |
| 氧化旧金 | `#988255` |
| 压力暗红 | `#7C302D` |

旧金仅用于编号、细分隔线和印章边缘。

## 字体

- 英文章节标题：Cormorant Garamond 600/700。
- 英文正文：Source Serif 4 400/600。
- 中文标题与正文：Noto Serif SC 400/600。
- 系统信息：IBM Plex Mono 500/600。
- 所有字体均由 `assets/fonts/` 自托管；不引入未使用字重。
- 手机中文正文不低于 17px，正文行高 1.75–1.82，不为中文增加夸张字距。

## 桌面网格

- 总宽约 1120px，三栏非对称网格。
- 左栏：幕、回合、四条编辑刻度与关系墨线。
- 中栏：约 704px 的实色纸页。
- 右栏：章节批注、条件旗标和印章。
- 英文长标题必须为页边批注预留至少 170px，不得相撞。

天堂占优时排版与分隔趋向整齐；地狱占优时页边批注略微越界；人间占优时苔绿批注形成自己的规则。表现保持克制，不改变可读性。

## 核心组件

- 状态条为细刻度尺，不使用常规圆角进度条。
- 选项是三条修订意见：编号、方向提示、2–3px 批注位移；键盘焦点为高对比双线。
- 极端选项同时使用交叉线纹理和文字标签，不能只靠红色。
- 选择后未选项折叠，已选项与后果展开。
- 印章动画为下压、轻微错位和不均匀墨迹，时长约 420ms，不弹跳。
- 档案页使用纸纤维、压痕和页角；模态与结局不垂直居中长文本。

## 插画

- 3 张幕间版画与 6 张结局版画使用统一限色铜版蚀刻＋编辑线稿。
- 只使用物件、空间和匿名剪影，不模仿演员，不复用官方剧照。
- 桌面 AVIF 控制在约 350KB 内；每张有独立 `-mobile.avif` 裁切。
- 现有伦敦街景只用于封面和环境底图；旧书、杯子、眼镜和汽车不再漂浮在四角。

## 移动端

- 900px 以下切换为紧凑吸顶栏、2×2 状态块和单列纸面阅读流。
- 触控目标至少 44×44px。
- 印章成为可滚动底部抽屉，抽屉内部保留继续按钮。
- 结局使用独立顶部起始滚动容器；320×568 下标题必须可见且页面无横向滚动。
- 新回合聚焦档案页，后果揭示聚焦后果区，模态必须约束焦点循环。

## 动效

- 页面显影 280–360ms。
- 选择展开约 320ms。
- 墨线与数值 180–260ms。
- 印章约 420ms。
- 幕间不超过 700ms，可立即点击继续。
- `prefers-reduced-motion: reduce` 下将动画与过渡缩短到近零。
