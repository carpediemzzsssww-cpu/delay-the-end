# 《Delay the End：附录 7B》规则规范

本文与 `game.js`、`data/game-config-v2.json`、`data/story-v2.json` 和 `data/simulate_balance.py` 使用同一套规则。

## 1. 一局的结构

- 总回合：10。
- 第一幕 R1–R3「没有阵营的世界」。
- 第二幕 R4–R7「回响申请复职」。
- 第三幕 R8–R10「创世第二稿」。
- 固定节点位于 R1、R4、R8、R10；其余位置从对应幕的未使用事件池中按种子与旗标确定性选择。
- R9 会同时考虑条件节点和无条件兜底节点，因此早期选择会改变候选池，而不是硬编码唯一后续。

## 2. 数值与关系

公开数值均 clamp 到 0–100：

| 字段 | 初始值 | 含义 |
|---|---:|---|
| `heaven` | 18 | 天堂回响：秩序、服从与完美计划，不等于善良 |
| `hell` | 18 | 地狱回响：欲望、混乱与自我意志，不等于自由 |
| `human` | 58 | 人间自由：犯错、犹豫、改变与自行选择的能力 |
| `pressure` | 8 | 重写压力：旧宇宙覆盖新现实的速度 |

隐藏关系为 `bond`、`memory`、`trust`，范围 -10–20。界面只以人物反应、墨线距离和页边文字表达。`evidence` 仅由真本等规则累积。

每回合结尾的压力增长依次为：`2, 2, 3, 3, 4, 4, 5, 5, 5, 6`。

## 3. 严格执行顺序

每个新回合：

1. 结算所有 `dueRound <= currentRound` 的延迟回调。
2. 回调数值、关系和旗标立即生效。
3. 依据幕、已使用节点、前置旗标和确定性种子选择当前事件。
4. 显示事件与三项选择；方向提示直接从实际 `effect` 生成。

玩家选择后：

1. 应用选择的公开数值。
2. 应用隐藏关系。
3. 写入旗标。
4. 注册本选择的延迟回调。
5. 展开精确后果并自动保存。
6. 玩家可盖一枚适用印章，也可不盖章。

继续归档时：

1. 应用本回合固定压力增长。
2. 记录最终快照。
3. R10 进入结局判定；否则进入下一回合并自动保存。

## 4. 档案印章

开局从 5 枚中装备 3 枚；默认推荐真本、交叉引用、删节。

| 印章 | 次数 | 规则 |
|---|---:|---|
| 真本 | 3 | `human +2`、`evidence +1`、`pressure +1` |
| 删节 | 2 | 抵消该选择最多 4 点正压力，`human -2`，并在两回合后触发审计 |
| 交叉引用 | 2 | 仅事件含 `crossref` 时可用；应用事件专属效果、关系与旗标 |
| 错置归档 | 2 | 较强阵营回响 `-3`、较弱阵营回响 `+1`，写入混乱旗标 |
| 永久封存 | 1 | 仅本选择创建延迟回调时可用；删除该回调、`pressure -5`，并永久丢失线索 |

每页最多使用一枚。不可用与次数耗尽的印章必须保持可辨认的禁用状态。

## 5. 结局优先级

结局严格按以下顺序判定：

1. `human < 25` → 人间空白。
2. `heaven >= 45 && hell >= 45` → 双重入侵。
3. `heaven >= 72 && heaven - hell >= 18` → 秩序复写。
4. `hell >= 72 && hell - heaven >= 18` → 混乱复写。
5. 同时满足以下条件 → 隐藏结局“普通的奇迹”：
   - `human >= 72`
   - `pressure < 80`
   - `bond >= 5`
   - `trust >= 4`
   - `evidence >= 3`
   - `abs(heaven - hell) <= 16`
6. 其他情况 → 附录封存。

人物尾声随后按关系判定：`bond >= 4 && memory >= 4` 为“他们记得”；仅 `bond >= 4` 为“他们不需要记得”；否则为“两条未交会的线”。

## 6. 存档、收藏与周目

- localStorage 存档版本为 2，每次选择、盖章与回合完成后写入。
- 版本 1 或旧 `stability` 字段会迁移为 `human`，保留基础阵营/压力值并标记迁移批注。
- 结局后删除进行中存档，但保留收藏、教程完成状态和上一结局。
- 收藏记录事件已见选择、结局和完成周目，不提供永久数值加成。
- 首次通关解锁 `data/events.json` 的 10 个旧宇宙残档。
- 上一结局会在下一局 R1 成为页边批注，并为第一次选择生成额外回应。

## 7. 自动化接口

- 随机事件由 FNV-1a 的 `seed:round:sortedFlags` 哈希确定。
- `window.render_game_to_text()` 返回回合、数值、关系、事件、可选项、印章、回调和结局。
- `window.advanceTime(ms)` 为测试循环提供确定性时间入口。
- 模拟器执行顺序必须与第 3 节一致。当前 10,000 × 5 策略报告要求六结局均可达，偏关系策略的隐藏结局概率目标为 5%–12%。
